# Datecs-DP150-Fleet-Console

This is working with Datecs DP150MX cash registers for **Romania**, i don't have other models to test!

1. You will need to set the cash register to work with a static ip address or use DHCP but reserve an ip address for this cash register!
2. Set cash register to be in mode 6 ( PC connection )
3. And now run the python script, access the webpage and add cash registers ;)


**What you can do with this tool?**

You can manage you fleet cash registers, read and set time/date, read and set VAT rates for the moment
